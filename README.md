# Franciscanos Frontend

Aplicativo web mobile-first para apoiar a vida fraterna franciscana.

## Funcionalidades atuais

- Menu com acesso a:
  - Músicas franciscanas
  - Material formativo
  - Fraternidade vinculada
  - Dados pessoais
- Dados mockados para desenvolvimento
- Camada de serviços preparada para integração com API

## Como executar

```bash
python3 -m http.server 4173
```

Acesse: `http://localhost:4173`
